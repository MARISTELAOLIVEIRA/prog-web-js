3. Passo a passo

1. Variável vazia: let resultado = ""; cria uma variável de texto que começa vazia. Cada bloco do if vai preenchê-la.
2. Decidir o conceito: O else if funciona igual ao exercício anterior, mas em vez de escrever na tela, só guarda o texto em resultado.
3. Mostrar uma vez só: No final, uma única linha coloca resultado na tela. Isso deixa o código mais organizado.
4. O console: console.log(resultado) escreve o valor no console do navegador. Ele é uma ferramenta para você conferir o código, o aluno que abre a página não vê.

4. Agora é com você!

Como testar com o console: na página, aperte F12 (ou clique com o botão direito e escolha Inspecionar) e abra a aba Console. Tudo que você escrever com console.log(...) aparece ali. É a melhor forma de "espiar" o que o código está fazendo.

Abra este arquivo no seu editor e faça as mudanças, uma de cada vez. Salve e atualize a página para ver o resultado.

  • Desafio 1 (fácil): Abra o console: aperte F12 (ou clique com o botão direito, Inspecionar) e escolha a aba Console. Você deve ver o conceito lá.
  • Desafio 2 (fácil): Mude a nota e atualize a página. Olhe a tela e o console.
  • Desafio 3 (médio): Adicione console.log(nota); antes do if para ver a nota no console.
