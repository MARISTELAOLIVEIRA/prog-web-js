3. Passo a passo

1. Duas variáveis: alturaEmMetros guarda um número e acompanhadoPelosPais guarda true ou false (verdadeiro ou falso).
2. O operador &&: && significa E. A condição só é verdadeira se as duas partes forem verdadeiras.
3. Comparar com ==: acompanhadoPelosPais == true verifica se o valor é verdadeiro. Repare: um = guarda valor, dois == comparam.
4. Resultado: Com altura 1.55 e sem acompanhante, a segunda parte é falsa. Então a condição inteira é falsa e roda o else.
