P1 · raio-x da linguagem

Afinal, o que é esse tal de JavaScript?

É a única linguagem que todo navegador entende de nascença. Ela roda dentro da página, no computador de quem visita, e transforma um documento parado em algo que responde.

  1. HTMLMonta a estrutura: títulos, botões, formulários.
  2. CSSDá cor, forma e lugar para cada coisa.
  3. JavaScriptEscuta o que acontece, como um click, e decide o que fazer.
  4. NavegadorAtualiza a página na hora, sem precisar recarregar.

C2 · origem

Nasceu em 10 dias

Em 1995, Brendan Eich criou o primeiro protótipo na Netscape em cerca de dez dias. Ainda bem que deu tempo de melhorar.

C3 · nome

Java e JavaScript? Nada a ver

Ela já se chamou Mocha e LiveScript. O "Java" no nome foi jogada de marketing da época. São linguagens diferentes.

C4 · em todo lugar

Do navegador ao ESP32

Roda no navegador, no servidor com Node.js, em aplicativos de celular e até em microcontroladores como o ESP32.

C5 · padrão

O nome oficial é ECMAScript

A linguagem segue um padrão chamado ECMAScript, que ganha uma versão nova todo ano. O ES2015 trouxe let, const e as arrow functions.

C6 · bug famoso

typeof null responde "object"

É um erro da primeira versão, de 1995. Nunca foi corrigido porque consertar quebraria metade da internet. Todo programador tropeça nele um dia.

Aonde a gente quer chegar

Capacitar os alunos com as habilidades técnicas e profissionais para aplicar os fundamentos da linguagem JavaScript, estruturas de controle, funções, arrays, objetos e manipulação de eventos, bem como conhecer frameworks de front-end e back-end, no desenvolvimento de soluções para a web no cenário profissional de tecnologia da informação.

  • Conhecer frameworks de front-end e back-end utilizados no desenvolvimento web com JavaScript.
U1–U5 · conteúdo programático

Cinco unidades, do console ao framework

Cada unidade liga um componente novo na placa. As quatro primeiras têm módulos no curso interativo.

Unidade 1módulo 1

Fundamentos da linguagem

Onde a página começa a pensar.

  • Introdução ao JavaScript e seu papel no desenvolvimento web
  • Sintaxe básica, variáveis e tipos de dados
  • Operadores aritméticos, relacionais e lógicos
  • Inserção de scripts em páginas HTML
Unidade 2módulos 2 e 3

Decisão e repetição

O código escolhe caminhos, repete sem cansar e fica legível para quem vem depois.

  • Estruturas condicionais (if, else, switch)
  • Estruturas de repetição (for, while, do-while)
  • Boas práticas de organização e legibilidade do código
Unidade 3módulo 4

Funções

Um bloco com nome próprio, que só trabalha quando é chamado.

  • Declaração e invocação de funções
  • Parâmetros, argumentos e retorno de valores
  • Funções anônimas e arrow functions
  • Escopo de variáveis
Unidade 4módulos 5 a 7

Arrays, objetos e eventos

Listas, fichas e cliques: a página começa a conversar com o usuário.

  • Arrays: criação, métodos e manipulação de dados
  • Objetos: propriedades, métodos e notação JSON
  • Manipulação do DOM (Document Object Model)
  • Tratamento de eventos (cliques, formulários, teclado)
Unidade 5seminários

Frameworks de front-end e back-end

O mapa do mercado: React na tela, Node.js no servidor.

  • Panorama dos frameworks e bibliotecas JavaScript do mercado
  • Introdução a frameworks de front-end (ex.: React)
  • Introdução a frameworks de back-end (ex.: Node.js)
  • Boas práticas na escolha de frameworks para projetos web

M1 · metodologia

Do console ao projeto integrador

Explicação curta, laboratório longo. Os scripts começam no console do navegador (o F12 vai virar seu melhor amigo) e crescem até virar páginas interativas, com estudos de caso de DOM e eventos.

Ao longo do semestre, cada um constrói uma aplicação web funcional no projeto integrador, usando um framework de front-end e/ou back-end. E tem seminário relâmpago para comparar os frameworks do mercado.

Curto-circuito? Abre o console, confere a trilha e tenta de novo.
