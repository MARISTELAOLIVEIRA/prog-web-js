Laços de Repetição

Ao final deste módulo, você será capaz de:

  • Repetir um bloco de código um número definido de vezes com for;
  • Repetir enquanto uma condição for verdadeira com while e do...while;
  • Usar break e continue para controlar um laço;
  • Evitar loops infinitos.

1. for: quando você sabe quantas vezes repetir

O laço for tem três partes separadas por ponto e vírgula: início, condição e incremento.

for (let i = 1; i <= 5; i++) {
  console.log("Contando: " + i);
}
// i começa em 1, repete enquanto i <= 5, e aumenta 1 a cada volta

2. while: repete enquanto a condição for verdadeira

Use quando não souber exatamente quantas repetições vão acontecer — importante lembrar de alterar a variável dentro do laço, senão ele nunca termina!

let energia = 100;

while (energia > 0) {
  console.log("Energia restante: " + energia);
  energia -= 25;
}
Atenção — loop infinito: se você esquecer de alterar a variável usada na condição (como o energia -= 25 acima), o laço nunca termina e trava o navegador. Sempre confira se a condição vai se tornar falsa em algum momento.

3. do...while: executa pelo menos uma vez

Parecido com o while, mas testa a condição depois de executar o bloco — então ele sempre roda ao menos uma vez.

let numero = 10;

do {
  console.log("Executou pelo menos uma vez. Número: " + numero);
  numero++;
} while (numero < 5); // condição falsa, mas já executou 1 vez

4. break e continue

  • break — interrompe o laço imediatamente
  • continue — pula para a próxima repetição, sem executar o resto do bloco atual
for (let i = 1; i <= 10; i++) {
  if (i === 6) break;          // para quando chegar em 6
  if (i % 2 === 0) continue;   // pula números pares
  console.log(i);              // imprime só ímpares até 5
}

5. Percorrendo um array com for

Um uso muito comum de for é percorrer todos os itens de um array, usando o índice:

let frutas = ["maçã", "banana", "uva"];

for (let i = 0; i < frutas.length; i++) {
  console.log(i + ": " + frutas[i]);
}
