Estruturas Condicionais

Ao final deste módulo, você será capaz de:

  • Usar if, else if e else para tomar decisões;
  • Usar switch quando houver muitos casos possíveis;
  • Usar o operador ternário para condições simples de uma linha.

1. if / else

Uma estrutura condicional executa um bloco de código somente se uma condição for verdadeira. A condição fica entre parênteses e o bloco entre chaves { }. 

let idade = 16;

if (idade >= 18) {
  console.log("Você é maior de idade.");
} else {
  console.log("Você é menor de idade.");
}

2. else if: várias condições em sequência

Quando há mais de duas possibilidades, encadeamos com else if:

let nota = 7.5;

if (nota >= 9) {
  console.log("Conceito A");
} else if (nota >= 7) {
  console.log("Conceito B");
} else if (nota >= 5) {
  console.log("Conceito C");
} else {
  console.log("Conceito D - reprovado");
}
Dica: o JavaScript testa as condições na ordem e para na primeira que for verdadeira. Por isso a ordem dos else if importa!

3. switch: quando comparamos um valor com várias opções exatas

O switch é útil quando comparamos uma mesma variável com vários valores possíveis, como no exemplo do dia da semana: 

let diaDaSemana = 3;
let nomeDoDia;

switch (diaDaSemana) {
  case 1:
    nomeDoDia = "Domingo";
    break;
  case 2:
    nomeDoDia = "Segunda-feira";
    break;
  case 3:
    nomeDoDia = "Terça-feira";
    break;
  default:
    nomeDoDia = "Dia inválido";
}

console.log(nomeDoDia);
Atenção: não esqueça do break! Sem ele, o código continua executando os próximos case mesmo depois de encontrar o valor certo (isso se chama "fall-through").

4. Operador ternário: um if/else compacto

Para decisões simples de uma linha, o operador ternário condição ? valorSeVerdadeiro : valorSeFalso é bem prático:

let idade = 20;
let status = idade >= 18 ? "adulto" : "menor de idade";
console.log(status);
