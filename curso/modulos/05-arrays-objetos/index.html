Arrays e Objetos

Ao final deste módulo, você será capaz de:

  • Criar e acessar itens de um array pelo índice;
  • Usar os métodos mais comuns de array: push, pop, length;
  • Criar objetos para representar dados com várias propriedades;
  • Acessar e alterar propriedades de um objeto.

1. Arrays: listas de valores

Um array guarda vários valores em uma única variável, em uma ordem definida. Cada posição tem um índice, começando sempre em 0. 

let frutas = ["maçã", "banana", "uva"];

console.log(frutas[0]); // "maçã"  (primeiro item, índice 0)
console.log(frutas[2]); // "uva"   (terceiro item, índice 2)
console.log(frutas.length); // 3   (quantidade de itens)

2. Adicionando e removendo itens

  • push(valor) — adiciona um item no final do array
  • pop() — remove e devolve o último item do array
let numeros = [1, 2, 3];
numeros.push(4);
console.log(numeros); // [1, 2, 3, 4]

let ultimo = numeros.pop();
console.log(ultimo);  // 4
console.log(numeros); // [1, 2, 3]

3. Objetos: dados com várias propriedades

Enquanto o array organiza valores por posição, o objeto organiza valores por nome (chamado de "chave" ou "propriedade"). É ótimo para representar algo do mundo real, como uma pessoa: 

let pessoa = {
  nome: "Fernanda",
  idade: 28,
  ativo: true,
};

console.log(pessoa.nome);   // "Fernanda"   (notação de ponto)
console.log(pessoa["idade"]); // 28         (notação de colchetes)

pessoa.idade = 29; // alterando uma propriedade
console.log(pessoa.idade); // 29
Dica: use a notação de ponto (objeto.propriedade) na maioria dos casos. Use colchetes (objeto["propriedade"]) quando o nome da propriedade estiver em uma variável ou tiver espaços/caracteres especiais.

4. Arrays de objetos

É muito comum combinar os dois: uma lista de objetos, como uma turma de alunos:

let alunos = [
  { nome: "Ana", nota: 8.5 },
  { nome: "Bruno", nota: 6.0 },
  { nome: "Carla", nota: 9.2 },
];

for (let i = 0; i < alunos.length; i++) {
  console.log(alunos[i].nome + ": " + alunos[i].nota);
}
