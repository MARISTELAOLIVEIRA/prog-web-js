Calculadora com HTML, CSS e JavaScript

O que você vai praticar

  • Montar um projeto com os três arquivos: index.html, estilo.css e script.js;
  • Dar cara de aplicativo à calculadora com CSS;
  • Ler os campos, fazer a conta com switch e mostrar o resultado na página;
  • Avisar os erros na tela: campo vazio e divisão por zero.

1. Experimente

Esta é a pasta do projeto, como você vê no VS Code. Use a calculadora lá embaixo: digite dois números, escolha a operação e clique em Calcular. Depois, passeie pelas abas e veja quem faz o quê.

2. Os três arquivos, um de cada vez

index.html: a estrutura

  • O <link> no <head> chama o estilo.css, e o <script> no fim do <body> chama o script.js.
  • Os dois números são <input type="number">. O step="any" aceita números com vírgula, como 2,5.
  • A operação é um <select>: cada <option> tem um value (o que o JavaScript lê) e um texto (o que o usuário vê).
  • Cada campo tem um <label for> ligado ao seu id.
  • O resultado aparece no <p id="resultado">. O aria-live="polite" faz o leitor de tela anunciar cada conta.

estilo.css: a aparência

  • O body usa display: grid e place-items: center para pôr a calculadora no meio da tela.
  • A classe .calculadora é o "corpo" do aparelho: fundo escuro, cantos arredondados e sombra. O max-width deixa ela encolher no celular.
  • input:focus e select:focus acendem o campo onde está o cursor.
  • .resultado.erro pinta o visor de vermelho. Quem liga essa classe é o JavaScript.

script.js: o comportamento

  • document.querySelector() acha cada elemento pelo id, igualzinho ao seletor do CSS.
  • A função calcular() recebe os dois números e a operação e devolve a conta, com switch.
  • A função formatar() usa toLocaleString("pt-BR") para mostrar o número do jeito brasileiro: 2,5 em vez de 2.5.
  • O evento submit junta tudo quando o usuário clica em Calcular (ou aperta Enter).

3. Do clique ao resultado, passo a passo

1. Evento: o clique em Calcular dispara o submit do formulário. O preventDefault() segura a página, que senão recarregaria.
2. Validação: se algum campo está vazio, a função mostra o aviso e o return para tudo ali. Cuidado: Number("") dá 0, por isso conferimos o texto do campo antes.
3. Conversão: tudo o que vem de um campo é texto. O Number() transforma em número. Sem ele, "2" + "3" dá "23".
4. Cálculo: o switch compara a operação com cada case e devolve só a conta que combina. Dividir por zero é barrado antes, com um aviso.
5. Resultado: o textContent escreve a conta no visor e o classList liga ou desliga a classe erro, para o CSS cuidar da cor.

4. Fora da tela: STEAM

Eletrônica

A calculadora de bolso faz o mesmo caminho: as teclas são a entrada, o chip faz a conta e o visor mostra. Aqui, o formulário, o script.js e o parágrafo do resultado.

Matemática

Some 0,1 + 0,2 na calculadora: dá 0,3. Sem o formatar(), daria 0.30000000000000004, porque o computador guarda números em binário.

Arte

A calculadora é sua: troque as cores no estilo.css, mude o formato do botão, dê a ela a cara de uma calculadora retrô.

5. Agora é com você: duas operações novas

Desafios extras (sem correção automática)

  • Desafio 1 (fácil): no estilo.css, troque a cor do botão e do visor.
  • Desafio 2 (médio): crie um botão Limpar, com type="reset", que apaga os campos. Faça o visor voltar para "Resultado: –".
  • Desafio 3 (difícil): guarde cada conta num array e mostre o histórico numa lista <ul> embaixo do visor.
