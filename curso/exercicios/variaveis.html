3. Passo a passo

1. Criar a variável: let idade = 16; cria uma "caixinha" chamada idade e guarda o número 16 dentro dela.
2. Fazer a pergunta: if (idade >= 18) pergunta: a idade é maior ou igual a 18? A resposta é sempre verdadeiro ou falso.
3. Escolher o caminho: Se for verdadeiro, roda o bloco do if. Se for falso, roda o bloco do else. Nunca os dois.
4. Mostrar na tela: A linha com document.getElementById("resposta").innerText escreve a mensagem no parágrafo da página. Isso é o DOM, que vamos estudar mais à frente. Por enquanto, basta saber que ela mostra o resultado.

4. Agora é com você!

Como testar com o console: na página, aperte F12 (ou clique com o botão direito e escolha Inspecionar) e abra a aba Console. Tudo que você escrever com console.log(...) aparece ali. É a melhor forma de "espiar" o que o código está fazendo.

Abra este arquivo no seu editor e faça as mudanças, uma de cada vez. Salve e atualize a página para ver o resultado.

  • Desafio 1 (fácil): Logo depois de let idade = 16;, escreva console.log(idade);, salve, atualize e olhe o console.
  • Desafio 2 (fácil): Mude o valor de idade para 20. O que aparece na tela e no console?
  • Desafio 3 (fácil): Mude as duas mensagens para frases suas.
  • Desafio 4 (médio): Crie uma variável nome e coloque o nome na mensagem usando crases: `${nome} pode tirar a habilitação!`
  • Desafio 5 (médio): Teste com idade = 18. Por que a mensagem é de "pode dirigir"? O que mudaria se você trocasse >= por >?
