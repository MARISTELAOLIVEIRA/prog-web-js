Fac Senac DF Aula 15 Projeto Projeto integrador

Oficina de ajustes

Cada grupo traz o projeto, a gente abre o capô junto e aperta os parafusos.

Objetivo do dia

Revisar o projeto integrador com a professora e sair com a lista do que falta, por ordem de prioridade.

Antes da aula

Trazer o projeto publicado no GitHub Pages e a lista de dúvidas do grupo.

Como conta ponto

Acompanhamento do projeto integrador. A nota vem na apresentação final.

R1 · roteiro

Como vai ser o encontro

  1. Raio-X do projeto

    R1

    Cada grupo mostra em dois minutos o que já funciona, o que está quebrado e o que ainda nem começou.

  2. Mentoria por grupo

    R2

    A professora passa em cada grupo. Vocês saem com uma lista de ajustes por prioridade: primeiro o que quebra, depois o que falta, por último o enfeite.

  3. Mão na massa

    R3

    Hora de corrigir: funcionalidades, README, publicação no GitHub Pages e acessibilidade.

  4. Revisão com IA

    R4

    Peça ao Copilot uma revisão do código e decida em grupo o que aceitar. Quem assina o código são vocês.

CU1 · caso de uso

O caso de uso principal do seu projeto

Ator: O usuário do projeto do grupo

Objetivo: Fazer a tarefa mais importante do sistema, do começo ao fim.

Fluxo principal

  1. Escrevam quem é o ator e qual é o objetivo.
  2. Listem os passos do fluxo principal.
  3. Executem o projeto seguindo os passos, um por um.
  4. Anotem onde travou: isso vai para a lista de ajustes.

E se...

  • Escrevam pelo menos dois "e se..." (dado errado, campo vazio, internet fora).

Para pensar

  1. O fluxo principal funciona do começo ao fim, sem ajuda?
  2. Qual "e se..." ainda quebra o projeto?

S1 · conexão STEAM

Bancada de testes

E

Engenharia

Nenhuma placa sai da bancada sem teste. Software também não: testar, achar o defeito, corrigir e testar de novo é o ciclo de qualquer engenheiro.

A

Artes

O usuário julga pelo que vê. Cores com contraste, botões claros e textos curtos também são acabamento.

M

Matemática

Priorizar é comparar custo e impacto: o ajuste que dá mais resultado com menos esforço vai primeiro.
