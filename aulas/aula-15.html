Do VS Code ao ar

Hoje a sua página ganha um endereço na internet. De verdade, para mandar para quem você quiser.

Objetivo do dia

Publicar a sua primeira página no GitHub Pages e conhecer a entrega final.

Antes da aula

Ter uma conta no github.com e saber a senha. Ainda não tem? Crie no começo da aula.

Como conta ponto

A página publicada hoje é o primeiro degrau da entrega final individual (7,0 pontos, apresentada na aula 17).

P1 · o problema

No seu computador, só você vê

Até hoje, as suas páginas abriam com um endereço como file:///C:/Users/…/index.html. Esse endereço só existe no seu computador: mande para um amigo e ele vê um erro.

Pense num bolo: no seu computador, ele está na sua cozinha. Para todo mundo provar, ele precisa ir para a vitrine de uma padaria, com endereço na rua. O GitHub é a padaria, e o GitHub Pages é a vitrine: ele mostra de graça páginas em HTML, CSS e JavaScript, num endereço como https://seu-usuario.github.io/minha-pagina/.

T1 · tutorial

Mão na massa: a sua página no ar em 6 passos

Um passo de cada vez. No fim da aula, você sai com um link que abre no celular de qualquer pessoa.

Passo 1

Monte a pasta no VS Code

A página-modelo é um interruptor: o botão acende e apaga uma lâmpada, com um if/else. São os três arquivos de sempre, cada um com a sua função.

Faça assim:
  1. Crie uma pasta chamada minha-pagina e abra no VS Code: Arquivo › Abrir pasta.
  2. Crie os arquivos index.html, estilo.css e script.js, com esses nomes exatos, tudo em minúsculas.
  3. Copie os três arquivos daqui (botão ⧉ Copiar o arquivo em cada aba) e salve cada um (Ctrl + S).

Regra do GitHub Pages: a página inicial se chama index.html. É ela que abre quando alguém entra no seu link. Com outro nome (pagina.html, Index.html, index.htm), o link dá erro 404. Vale para qualquer site, não só para este.

Passo 2

Teste no seu computador

Faça assim:
  1. Abra o index.html com o Live Server (botão direito no arquivo › Open with Live Server) ou com dois cliques.
  2. Clique no botão: a lâmpada acende, o fundo clareia e o texto muda. Clique de novo: apaga.

Regra de ouro: só publique o que já funciona no seu computador. Se aqui não funciona, lá também não vai funcionar.

Passo 3

Crie o repositório no GitHub

O repositório é a pasta do seu projeto lá no GitHub. As telas do GitHub são em inglês: os nomes dos botões estão em negrito, igualzinho ao que aparece.

Faça assim:
  1. Entre no github.com e clique no +, no alto da tela, e depois em New repository.
  2. Em Repository name, escreva minha-pagina (sem espaços nem acentos: o nome vai para o endereço).
  3. Deixe marcado Public. O GitHub Pages grátis só funciona com repositório público.
  4. Clique em Create repository.
Passo 4

Envie os três arquivos

Faça assim:
  1. No repositório novo, clique no link uploading an existing file. Se o repositório já tiver arquivos, use Add file › Upload files.
  2. Arraste os três arquivos para a janela. Os arquivos, não a pasta minha-pagina!
  3. Espere aparecerem os três na lista e clique em Commit changes.

Pegadinha clássica: arrastou a pasta inteira? Os arquivos ficam em minha-pagina/index.html, e o endereço da página muda. O index.html precisa aparecer logo na primeira tela do repositório.

Passo 5

Ligue o GitHub Pages

Faça assim:
  1. No repositório, clique em Settings (a engrenagem, no alto).
  2. No menu da esquerda, clique em Pages.
  3. Em Source, deixe Deploy from a branch.
  4. Em Branch, escolha main e a pasta / (root). Clique em Save.
Passo 6

Abra o seu link

Faça assim:
  1. Espere 1 a 2 minutos. Na aba Actions do repositório, a tarefa pages build and deployment fica com o ✅ verde quando termina.
  2. Volte em Settings › Pages: lá em cima aparece Your site is live at e o seu link. Ele segue o modelo https://seu-usuario.github.io/minha-pagina/.
  3. Abra o link no computador e no celular. Clique no interruptor. 💡
  4. Mande o link para alguém. Parabéns: a sua página está na internet!
E depois?

Mudou a página? Atualize assim

Faça assim:
  1. Mude no VS Code e teste no seu computador.
  2. No repositório, Add file › Upload files, arraste os arquivos que mudaram (com o mesmo nome: eles substituem os antigos) e Commit changes.
  3. Espere o ✅ verde em Actions e recarregue a página com Ctrl + Shift + R (no Mac, Cmd + Shift + R).

Já usa o Git no VS Code? Também vale: git add ., git commit -m "…" e git push fazem o mesmo que o upload.

C1 · deu ruim?

Os erros mais comuns (e o conserto)

O que aconteceuPor quêConserto
Erro 404 no linkNão há index.html na primeira tela do repositório: o nome está diferente (Index.html, index.htm) ou os arquivos estão dentro de uma pasta.Renomeie para index.html ou envie os arquivos soltos, sem a pasta.
A página aparece sem corO nome no <link href="estilo.css"> não bate com o arquivo. No GitHub, Estilo.css e estilo.css são arquivos diferentes.Use tudo em minúsculas, igualzinho nos dois lugares.
O botão não faz nadaO script.js não carregou (nome diferente) ou o <script> está antes do botão.Confira o nome e deixe o <script src="script.js"> no fim do <body>.
Mudei e não mudouO GitHub ainda está publicando, ou o navegador mostrou a versão guardada.Espere o ✅ em Actions e aperte Ctrl + Shift + R.
Não aparece a opção Pages ou ela pede pagamentoO repositório está como Private.Settings › General, lá no fim, Change visibility para Public.
F1 · a entrega final

A sua página, do seu jeito

Individual. A página de hoje é só o começo: troque o interruptor por um projeto seu, escolhendo uma das três ideias.

🧰 Caixa de ferramentas

De 1 a 3 mini-apps úteis: calculadora de IMC, gerador de senha, conversor de unidades, divisor da conta do bar…

🏪 Um cliente fictício

A página de um negócio inventado: cafeteria, pet shop, barbearia. Com cardápio, botões e um aviso de "aberto agora".

🎮 Um jogo simples

Adivinhe o número, pedra-papel-tesoura ou um quiz sobre um tema que você curte.

Os degraus da nota

DegrauO que a sua página precisa terPontos
🥉 Mínimoa página inicial se chama index.html, com estilo.css e script.js separados; um botão que muda a página com if/else; o link no GitHub Pages funcionando4,0
🥈 Intermediáriolê o que a pessoa digitou num campo e valida (campo vazio, letra no lugar de número)+1,5
🥇 Completousa uma lista (array) com laço, ou guarda algo com localStorage (o recorde do jogo, o último cálculo)+1,0
🎤 Apresentaçãona aula 17, abre o link ao vivo e explica uma linha do código escolhida pela professora+0,5

Vergonha de aparecer? Não precisa de foto nem de "sobre mim". Assine com o nome ou com um codinome: quem aparece é o projeto.

S1 · conexão STEAM

O interruptor de verdade

E

Engenharia

No Arduino, um botão e um LED fazem exatamente o que o seu if/else faz: lê o botão, decide e acende ou apaga. A lógica é a mesma, só o "hardware" muda.

A

Artes

O fundo que clareia quando a luz acende é design de interação: a página responde ao gesto da pessoa.

T

Tecnologia

Hospedar um site já foi caro e difícil. Hoje, um repositório público e três cliques põem a sua página no mundo.

D1 · desafio extra

Terminou antes? Tem mais.

Conte quantas vezes a luz foi acesa e mostre na página ("Você acendeu a luz 3 vezes"). Depois, troque a lâmpada pelo começo do seu projeto da entrega final e publique de novo.
