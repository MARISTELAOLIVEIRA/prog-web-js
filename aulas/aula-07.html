P1 · o problema

Código repetido é convite para erro

Olhe o Sistema de Aprovação: a mesma conta de média aparece em vários lugares. Se a regra mudar, você vai lembrar de trocar em todos? A solução é dar um nome para esse pedaço de código e chamá-lo quando precisar.

repetido.js 
1const media1 = (8 + 7 + 9) / 3;2const media2 = (5 + 6 + 7) / 3;3const media3 = (10 + 9 + 8) / 3;4// e se a média passar a ter peso?5// trocar em 40 lugares...
C1–C3 · conceitos

Funções em três peças

C1

Declarar e chamar

A função é declarada uma vez, com function e um nome, e chamada quantas vezes quiser, com o nome e parênteses.

1function saudar() {2  console.log("Bem-vindos, filhotes!");3}45saudar();   // chama uma vez6saudar();   // e de novo
C2

Parâmetros e argumentos

Parâmetros são as variáveis que a função recebe, na declaração. Argumentos são os valores que você manda na chamada.

1function saudar(nome) {        // nome é o parâmetro2  console.log(`Oi, ${nome}!`);3}45saudar("Ana");     // "Ana" é o argumento6saudar("Caio");
C3

Retorno com return

O return devolve um resultado para quem chamou. Com ele, uma função pode alimentar outra.

Depois do return, a função para.

1function calcularMedia(n1, n2, n3) {2  return (n1 + n2 + n3) / 3;3}45function verificarSituacao(media) {6  return media >= 6 ? "Aprovado" : "Recuperação";7}89const media = calcularMedia(8, 7, 9);   // 810console.log(verificarSituacao(media));  // Aprovado
