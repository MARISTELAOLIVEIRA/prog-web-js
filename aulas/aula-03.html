C1–C3 · conceitos

As caixinhas da memória

C1

Variável: um nome para um valor

Uma variável é uma caixinha com etiqueta na memória. Use let quando o valor pode mudar e const quando não muda.

O var é o jeito antigo. Você vai encontrá-lo em código velho, mas aqui a gente usa let e const.

Nomes em camelCase: nomeCompleto, notaFinal.

1let idade = 19;          // pode mudar2const curso = "ADS";     // não muda34idade = 20;              // tudo certo5// curso = "SI";         // erro: const não aceita novo valor67let nomeCompleto = "Ana Souza";  // camelCase
C2

Os tipos primitivos

Todo valor tem um tipo. Os primitivos são: number, string, boolean, undefined e null.

O typeof conta o tipo. Template strings, com crase, encaixam variáveis no texto com ${}.

Cuidado: typeof null responde "object". É um erro histórico da linguagem, de 1995, que nunca foi corrigido.

1typeof 8.5;          // "number"2typeof "Stela";      // "string"3typeof true;         // "boolean"4typeof undefined;    // "undefined"56const nome = "Bia";7console.log(`Oi, ${nome}!`);   // Oi, Bia!
C3

Entrada, conversão e saída

O prompt() pergunta, o alert() avisa e o console.log() mostra no Console.

Tudo o que vem do prompt() é texto. Para fazer conta, converta com Number(), parseInt() ou parseFloat().

Cuidado: "19" + 1 dá "191", porque junta textos. Number("19") + 1 dá 20.

1const texto = prompt("Quantos anos você tem?");2const idade = Number(texto);34console.log(texto + 1);    // "191"  (juntou textos)5console.log(idade + 1);    // 20     (somou números)67parseInt("7.9");     // 78parseFloat("7.9");   // 7.9
CU1 · caso de uso

Preencher a ficha de cadastro

Ator: Secretaria da escola

Objetivo: Guardar os dados de um aluno novo.

Fluxo principal

  1. A secretaria informa o nome do aluno.
  2. Informa a idade.
  3. Informa se a matrícula está ativa.
  4. O sistema mostra a ficha conferida na tela.

E se...

  • A idade é digitada como texto ("dezoito"): o sistema precisa perceber que não é número.

Para pensar

  1. Que variável guarda cada dado? Qual é o tipo de cada uma (string, number, boolean)?
  2. Quais desses dados podem mudar depois e quais não? (let ou const?)
