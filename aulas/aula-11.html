P1 · o problema

O console é ótimo, mas o usuário não abre o F12

Até agora tudo apareceu no console. Usuário de verdade não vê console: vê a página. Hoje o Cadastro de Alunos ganha interface. Para isso, a turma vai desenhar no Whiteboard a árvore de uma página HTML, com cada tag como um galho.

C1–C3 · conceitos

O DOM em três movimentos

C1

A árvore DOM

Quando o navegador lê o HTML, ele monta uma árvore de objetos na memória: o DOM (Document Object Model).

Cada tag vira um nó, com pais e filhos. O JavaScript mexe nessa árvore, e a página muda na hora.

1<body>2  <h1 id="titulo">Cadastro</h1>3  <ul class="lista">4    <li>Ana</li>5    <li>Bia</li>6  </ul>7</body>
C2

Selecionando elementos

getElementById() pega pelo id. querySelector() pega o primeiro que bate com um seletor CSS. querySelectorAll() pega todos.

No DevTools, a aba Elements mostra essa árvore ao vivo.

1const titulo = document.getElementById("titulo");2const lista = document.querySelector(".lista");3const itens = document.querySelectorAll(".lista li");45console.log(itens.length);         // 26console.log(lista.children[0]);   // o primeiro li
C3

Mudando a página

textContent troca o texto. classList liga e desliga classes do CSS. createElement() e append() criam elementos novos, e remove() tira.

Cuidado: innerHTML interpreta HTML. Nunca coloque nele texto digitado pelo usuário: é uma porta aberta para ataques. Para texto, use textContent.

1titulo.textContent = "Cadastro de Alunos";2titulo.classList.add("destaque");34const novo = document.createElement("li");5novo.textContent = "Caio";6lista.append(novo);78itens[0].remove();   // tira a Ana

Antes de começar

Prepare a pasta e abra a página

Faça assim:
  1. No seu repositório programacao-web-js, crie a pasta aula11.
  2. Dentro dela, crie três arquivos vazios: index.html, estilo.css e script.js.
  3. Abra a pasta no VS Code: Arquivo › Abrir pasta.
  4. Para ver a página, clique com o botão direito no index.html e escolha Open with Live Server. O navegador abre sozinho e atualiza toda vez que você salva.

Como copiar o código de cada passo: clique na aba do arquivo (index.html, estilo.css ou script.js) e depois em ⧉ Copiar o arquivo. No VS Code, abra o mesmo arquivo, apague o que tinha (Ctrl + A e Delete), cole (Ctrl + V) e salve (Ctrl + S).

Sem o Live Server? Dê dois cliques no index.html para abrir no navegador. A cada mudança, salve no VS Code e aperte F5 no navegador.

Passo 1 · item 2 da atividade

O JavaScript escreve na página

O HTML monta a página e o JavaScript mexe nela depois. Para isso, o index.html precisa dizer onde está o script: a linha <script src="script.js"></script>, no fim do <body>.

getElementById("titulo") pega o elemento pelo id, sem o #. querySelector("#mensagem") faz o mesmo com um seletor do CSS, com o #. E o textContent troca o texto.

Faça assim:
  1. Copie os três arquivos deste passo para a sua pasta aula11 e salve.
  2. Abra a página com o Live Server.
  3. Confira: o título tem que ser Cadastro de Alunos, e não "Título provisório".
  4. Aperte F12 e abra a aba Elements: o <h1> já mostra o texto novo.
Teste:
  1. Mude o texto entre aspas do textContent, salve e veja a página mudar.
  2. Apague a linha <script src> do HTML. O que acontece? Depois, coloque a linha de volta.
  3. Troque id="titulo" por id="cabecalho" só no HTML e abra o Console (F12). Leia o erro e conserte.

Continua "Título provisório"? O script não rodou: confira se o nome no src é igual ao do arquivo e se o script.js está na mesma pasta. Apareceu Cannot set properties of null? O id do HTML e o do JavaScript estão diferentes. Maiúscula conta: titulo e Titulo são outro nome.

Funcionou? Guarde a versão: git add . e git commit -m "Aula 11: o JavaScript escreve na página".

Passo 2 · itens 1 e 3 da atividade

A tabela vazia e o querySelector

O index.html ganha uma <table> com o cabeçalho pronto (<thead>) e o corpo vazio: <tbody id="tabela"></tbody>. Quem vai preencher o corpo é o JavaScript.

querySelector("#tabela") acha o tbody e guarda na variável tabela. O children é a lista dos filhos dele: por enquanto, nenhuma linha.

Faça assim:
  1. Troque todo o index.html pelo deste passo.
  2. Troque o estilo.css: ele ganhou o visual da tabela.
  3. Troque o script.js.
  4. Salve os três e confira: aparece "Achei a tabela! Ela tem 0 linhas."
Teste:
  1. Escreva errado de propósito: querySelector("#tabelas"). A página para de funcionar e o Console mostra um erro com null.
  2. Conserte. Esse null é o erro mais comum do DOM: quer dizer "não achei esse elemento". Quando aparecer, confira o id.

Funcionou? git add . e git commit -m "Aula 11: a tabela vazia".

Passo 3 · itens 4 e 5 da atividade

A primeira linha, peça por peça

Para pôr uma linha na tabela são cinco movimentos, sempre nesta ordem:

Os cinco movimentos:
  1. Criar a linha: document.createElement("tr").
  2. Criar as células: um createElement("td") para cada coluna.
  3. Escrever o texto de cada célula com textContent.
  4. Pôr as células na linha: linha.append(...).
  5. Pôr a linha na tabela: tabela.append(linha).

Pegadinha: o createElement cria o elemento só na memória. Ele só aparece na página depois do append.

Faça assim:
  1. O index.html e o estilo.css são os mesmos do passo 2. Troque só o script.js.
  2. Salve: a Ana aparece na tabela.
  3. No F12, aba Elements, abra o <tbody> e ache o <tr> que o JavaScript criou.
Teste:
  1. Ponha // na frente da última linha (// tabela.append(linha);). A Ana some: a linha foi criada, mas não entrou na página. Tire o //.
Agora é com você:
  1. Crie uma segunda linha com o Bruno Lima, média 5.2, reprovado. Copie os cinco movimentos e troque os nomes das variáveis (linha2, celulaNome2…).
  2. Percebeu quanta repetição? O passo 4 resolve isso.
Passo 4 · itens 4 e 5 da atividade

Uma linha para cada aluno: o laço faz o trabalho

A turma vira uma lista de objetos, como na aula 10. O for...of visita um aluno por vez: a cada volta, aluno é um objeto, com aluno.nome e aluno.media. Dentro do laço, os mesmos cinco movimentos do passo 3.

O if decide o texto da situação: média 6 ou mais é aprovado.

Faça assim:
  1. Troque só o script.js.
  2. Salve: aparecem os três alunos.
Teste:
  1. Acrescente um quarto aluno na lista: { nome: "Davi Rocha", media: 9 }. Não esqueça a vírgula depois do } do aluno de cima.
  2. A tabela cresce sem você mexer no HTML.
Agora é com você:
  1. Troque a lista pela turma do seu Cadastro de Alunos (o array das aulas 9 e 10).
Passo 5 · item 6 da atividade

Aprovado em verde, reprovado em vermelho: classList

O JavaScript não pinta nada. As cores ficam no CSS, nas classes .aprovado e .reprovado. O JavaScript só escolhe a classe da linha: linha.classList.add(situacao).

Repare no let situacao: a decisão é tomada uma vez só e usada duas vezes, na classe e no texto. E o toFixed(1) mostra a média com uma casa decimal: 7 vira 7.0.

Faça assim:
  1. Troque o estilo.css: as duas classes novas estão no fim.
  2. Troque o script.js.
  3. Salve e veja as cores.
  4. No F12, aba Elements: cada <tr> ganhou class="aprovado" ou class="reprovado".
Teste:
  1. No CSS, troque a cor do .reprovado por laranja (#b85c00). Você mudou uma linha e todas as linhas reprovadas mudaram juntas.
Agora é com você:
  1. Crie a classe .destaque no CSS (por exemplo, font-weight: bold;) e ligue nas linhas com média 9 ou mais, com mais um if e classList.add("destaque").

Funcionou? git add . e git commit -m "Aula 11: tabela com cores".

Passo 6 · itens 7 e 8 da atividade

A versão final: funções, turma vazia e CSS caprichado

Três melhorias de programador. A função criarCelula(texto) cria a célula e já escreve o texto: três linhas viram uma. A função mostrarTurma(lista) desenha a tabela inteira e pode ser chamada de novo sempre que a lista mudar (é o que a aula 12 vai fazer).

E o "E se…" do caso de uso: se a lista está vazia (lista.length === 0), a tabela se esconde (hidden = true) e aparece o aviso "Nenhum aluno cadastrado".

O CSS ganhou o desafio criativo: cantos arredondados, sombra e a linha que escurece quando o mouse passa por cima.

Faça assim:
  1. Troque os três arquivos.
  2. Salve e passe o mouse sobre as linhas da tabela.
Teste:
  1. Na última linha, troque mostrarTurma(turma) por mostrarTurma([]): a tabela some e aparece o aviso. Depois, volte como estava.
Agora é com você (desafio criativo):
  1. Personalize o CSS do seu jeito: as cores da sua turma, outra fonte, um emoji na situação (✅ ou ❌).
  2. Quer mais? Faça o desafio extra lá embaixo: aprovados e média geral no topo da página.

CU1 · caso de uso

Ver a turma numa tabela

Ator: Professora

Objetivo: Ver os alunos e as situações na página, sem abrir o console.

Fluxo principal

  1. A professora abre a página do sistema.
  2. O JavaScript lê a lista de alunos.
  3. Cria uma linha da tabela para cada aluno.
  4. Pinta de verde os aprovados e de vermelho os reprovados.

E se...

  • A turma ainda não tem alunos: a página mostra "nenhum aluno cadastrado" no lugar da tabela.

Para pensar

  1. Que elementos do HTML o JavaScript precisa selecionar?
  2. Mudar a cor é mexer no texto, no estilo ou na classe? Qual é melhor?

S1 · conexão STEAM

A árvore que vira página

S

Ciência

A árvore DOM é como uma árvore genealógica ou uma classificação de espécies: tudo tem pai, filhos e irmãos.

A

Arte

Com classList, o JavaScript troca a roupa da página: cores, tamanhos e animações mudam com um clique.

T

Tecnologia

Todo site que atualiza sem recarregar, do feed da rede social ao placar do jogo, está mexendo no DOM.
