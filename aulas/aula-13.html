C1–C3 · conceitos

O ecossistema em três ideias

C1

npm, biblioteca e framework

O npm é a loja de pacotes do JavaScript: milhões de códigos prontos para reaproveitar.

Biblioteca: você chama quando precisa (você manda). Framework: ele dá a estrutura e chama o seu código (ele manda).

NomeO que é
Reactbiblioteca de interface
Vue.jsframework de interface
Angularframework completo de front-end
Node.jsJavaScript no servidor
Expressframework de servidor para Node.js
C2

Seminário relâmpago

Cada grupo apresenta, em poucos minutos, o framework sorteado: o que é, para que serve, quem usa, vantagens e limitações.

Pesquise com o Copilot do Microsoft 365, mas confira tudo na documentação oficial. IA erra com muita confiança.

C3

Trabalho em equipe no GitHub

Issues dividem as tarefas. Cada pessoa trabalha numa branch. O pull request junta o trabalho depois que alguém revisa.

Assim ninguém apaga o código do colega sem querer.

1git checkout -b tela-de-cadastro   # nova branch2# ... programa, programa ...3git add .4git commit -m "Tela de cadastro"5git push origin tela-de-cadastro6# no GitHub: abrir o pull request
CU1 · caso de uso

O painel que se atualiza sozinho

Ator: Coordenação

Objetivo: Ver em tempo real quantos alunos estão em cada situação.

Fluxo principal

  1. A coordenação abre o painel.
  2. O painel mostra os totais por situação.
  3. Quando uma professora lança uma nota, o painel muda sem ninguém recarregar.

E se...

  • A internet cai: o painel avisa que os dados podem estar desatualizados.

Para pensar

  1. Que framework do seminário facilitaria esse painel? Por quê?
  2. Daria para fazer só com JavaScript puro? Com quanto esforço?
