C1–C3 · conceitos

Eventos em três camadas

C1

addEventListener: fique de olho

Um evento é algo que acontece: um clique, uma tecla, um envio. O addEventListener() diz qual função executar quando ele acontecer.

A função recebe o objeto event, com detalhes do que aconteceu.

1const botao = document.querySelector("#salvar");23botao.addEventListener("click", (event) => {4  console.log("Clicou!", event.type);   // Clicou! click5});
C2

Mouse, teclado e formulário

Mouse: click, dblclick, mouseover. Teclado: keydown, keyup. Formulário: submit, input, change.

O input dispara a cada letra digitada: perfeito para filtrar em tempo real.

1const busca = document.querySelector("#busca");23busca.addEventListener("input", () => {4  const termo = busca.value.toLowerCase();5  const achados = turma.filter((a) =>6    a.nome.toLowerCase().includes(termo)7  );8  mostrarTabela(achados);9});
C3

Formulário sem recarregar

Ao enviar, o formulário recarrega a página por padrão. O preventDefault() impede isso, e você trata os dados no JavaScript.

Valide antes de cadastrar: campo vazio e nota fora de 0 a 10 não passam.

1const form = document.querySelector("#form-aluno");23form.addEventListener("submit", (event) => {4  event.preventDefault();5  const nome = form.nome.value.trim();6  const nota = Number(form.nota.value);7  if (nome === "" || nota < 0 || nota > 10) {8    alert("Confira o nome e a nota");9    return;10  }11  turma.push({ nome, media: nota });12  mostrarTabela(turma);13});

Passo 1 · aquecimento

O primeiro clique: addEventListener

Até a aula 11, o script rodava uma vez, de cima para baixo, e acabava. Com o addEventListener("click", function () { ... }), a função fica esperando: ela só roda quando o clique acontece, e roda de novo a cada clique.

A variável cliques fica fora da função, para lembrar a contagem entre um clique e outro.

Faça assim:
  1. Copie os três arquivos para a sua pasta aula12 e salve.
  2. Clique no botão algumas vezes e veja a contagem subir.
Teste:
  1. Troque "click" por "dblclick": agora só conta o clique duplo.
  2. Troque por "mouseover": conta toda vez que o mouse passa por cima do botão. Depois, volte para "click".
  3. Mova a linha let cliques = 0; para dentro da função. O que acontece com a contagem? Por quê? Depois, volte para fora.
Passo 2 · item 1 da atividade

O formulário envia: submit e preventDefault

O HTML ganha um <form> com dois campos e um botão type="submit". Cada campo tem um name: é por ele que o JavaScript acha o valor, com form.nome.value e form.nota.value.

Repare que o evento é o submit do formulário, e não o click do botão. Assim o cadastro funciona com o clique e com o Enter, como pede o caso de uso.

Por que o event.preventDefault()? Ao enviar, o navegador recarrega a página. A página recomeça do zero, e a lista volta a ter só os alunos do começo. O preventDefault() diz: "deixa que o JavaScript cuida".

Faça assim:
  1. Troque os três arquivos: o index.html e o estilo.css ganharam o formulário, e o script.js traz a mostrarTurma() da aula 11.
  2. Digite um nome e uma nota e aperte Enter: aparece "Recebi: …".
Teste (no seu VS Code, com o Live Server):
  1. Ponha // na frente do event.preventDefault();, salve e envie o formulário. A página pisca e a mensagem some: ela recarregou. Tire o //.
  2. Envie com o nome vazio. O que aparece? O passo 3 resolve isso.

Passo 3 · item 2 da atividade

Validar antes de cadastrar

Dado digitado pelo usuário é suspeito até prova em contrário. Antes de cadastrar, duas conferências:

As duas regras:
  1. Nome vazio não passa. O trim() tira os espaços do começo e do fim: quem digita só espaços também é barrado.
  2. Nota tem que ser de 0 a 10. O campo devolve texto, por isso o Number() transforma em número antes de comparar.

Repare no novalidate do <form>: ele desliga a conferência automática do navegador (aquele balãozinho), para você ver a sua validação funcionando. Num sistema de verdade, as duas trabalham juntas.

Quando uma regra falha, o campo ganha a classe campo-erro (borda vermelha), a mensagem aparece na página, o cursor volta para o campo (focus()) e o return para tudo: nada é cadastrado.

Faça assim:
  1. Troque o estilo.css (as classes de erro estão no fim) e o script.js. O index.html é o mesmo do passo 2.
  2. Salve e faça os testes abaixo.
Teste:
  1. Envie com o nome vazio, depois só com espaços.
  2. Envie com a nota 11, depois -1, depois com a nota vazia.
  3. Envie certo: a borda vermelha some e aparece "Tudo certo".
Agora é com você:
  1. Crie uma terceira regra: o nome precisa ter pelo menos 3 letras (dica: nome.length < 3).
Passo 4 · item 3 da atividade

Cadastrar no array e atualizar a tabela

Passou nas regras? Três movimentos: colocar o aluno na lista com turma.push({ nome: nome, media: nota }), desenhar a tabela de novo com mostrarTurma(turma) e limpar o formulário com form.reset().

É por isso que a mostrarTurma() virou função na aula 11: agora ela é chamada de novo a cada cadastro.

Faça assim:
  1. Troque só o script.js.
  2. Cadastre dois alunos, um aprovado e um reprovado, e veja cada um entrar na tabela com a cor certa, sem recarregar a página.
Teste:

  2. Apague a linha mostrarTurma(turma); de dentro do submit. O aluno entra na lista, mas a tabela não muda. Coloque a linha de volta.

Passo 5 · item 4 da atividade

Busca enquanto digita: o evento input

O evento input dispara a cada letra digitada no campo de busca. A cada letra, o filter() monta uma lista só com os alunos cujo nome tem o que foi digitado (includes), e a mostrarTurma() desenha só esses.

O toLowerCase() deixa tudo em minúsculas dos dois lados: assim "ana" acha "Ana Souza".

Faça assim:
  1. Troque os três arquivos: o HTML ganhou o campo de busca.
  2. Digite "an" na busca, letra por letra, e veja a tabela filtrar.
  3. Apague a busca: a turma inteira volta.
Teste:
  1. Busque um nome que não existe, como "zé": aparece o aviso "Nenhum aluno com…".
  2. Tire os dois toLowerCase() e busque "ana" em minúsculas. O que muda? Coloque de volta.

Passo 6 · bônus

Clique duplo remove o aluno

Cada linha da tabela ganha o seu próprio "ouvinte": linha.addEventListener("dblclick", ...). Como ele é criado dentro do laço, cada linha lembra qual é o seu aluno.

Para tirar da lista: o indexOf(aluno) diz em que posição ele está, e o splice(posicao, 1) tira 1 item dessa posição (aula 9).

Faça assim:
  1. Troque os três arquivos.
  2. Clique duas vezes num aluno: ele sai da tabela e aparece o aviso.
Agora é com você:
  1. Faça o desafio extra da aula: a tecla Esc limpa a busca e mostra a turma inteira de novo. Dica: busca.addEventListener("keydown", ...) e event.key === "Escape".
CU1 · caso de uso

Cadastrar pelo formulário

Ator: Secretaria da escola

Objetivo: Cadastrar um aluno clicando num botão, como em qualquer sistema de verdade.

Fluxo principal

  1. A secretaria preenche o formulário.
  2. Clica em "Cadastrar".
  3. O sistema confere os campos.
  4. O aluno aparece na tabela na hora, sem recarregar a página.

E se...

  • Um campo obrigatório está vazio: o sistema destaca o campo e não cadastra.
  • A secretaria aperta Enter em vez de clicar: o cadastro funciona igual.

Para pensar

  1. Que evento cada passo escuta (click, submit, input)?
  2. Por que o preventDefault() aparece aqui?
