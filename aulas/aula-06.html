C1–C4 · conceitos

Laços e como controlá-los

C1

for: quando você sabe quantas vezes

O for tem três partes: começo, condição para continuar e passo. Perfeito para contar.

1// tabuada do 72for (let i = 1; i <= 10; i++) {3  console.log(`7 x ${i} = ${7 * i}`);4}
C2

while e do...while: até a condição mudar

O while repete enquanto a condição for verdadeira e pode nem começar. O do...while executa pelo menos uma vez antes de testar.

O do...while é ótimo para validar entrada: pergunta de novo até a resposta servir.

Cuidado: se a condição nunca ficar falsa, o laço é infinito e a aba trava. Use o depurador do navegador (aba Sources) para ver o que está acontecendo.

1let senha;2do {3  senha = prompt("Crie uma senha com 6 ou mais caracteres");4} while (senha.length < 6);56console.log("Senha aceita!");
C3

Contadores, acumuladores, break e continue

O contador conta quantas vezes algo aconteceu. O acumulador vai somando valores.

O break sai do laço na hora. O continue pula para a próxima volta.

1let soma = 0;       // acumulador2let aprovados = 0;  // contador34for (let i = 1; i <= 5; i++) {5  const nota = Number(prompt(`Nota do aluno ${i}`));6  if (nota < 0) continue;   // ignora nota inválida7  soma += nota;8  if (nota >= 6) aprovados++;9}10console.log(`Média: ${soma / 5}, aprovados: ${aprovados}`);
C4

Código que os outros entendem

Indentação certinha, nomes que dizem o que guardam (totalDeAlunos, não x) e comentários que explicam o porquê, não o óbvio.

Código é lido muito mais vezes do que é escrito, inclusive por você daqui a um mês.

S1 · conexão STEAM

Repetição é tudo

M

Matemática

Somatório (Σ) é um laço: somar de 1 a 100 dá 5050, como o jovem Gauss descobriu sem computador.

E

Eletrônica

O loop() do Arduino é um laço infinito de propósito: lê o sensor, decide e repete para sempre.

A

Arte

Padrões repetidos são arte: um laço desenha um mosaico, uma estampa ou uma escada de asteriscos.
