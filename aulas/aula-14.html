C1

React: componentes e estado

No React, a interface é feita de componentes: funções que devolvem pedaços de tela em JSX, uma mistura de JavaScript com HTML.

O useState guarda um valor que, quando muda, atualiza a tela sozinho. O projeto é criado com o Vite: npm create vite@latest.

C2

Node.js: JavaScript fora do navegador

Com o Node.js, o JavaScript roda no servidor. Com o Express, em poucas linhas, ele responde pedidos em JSON.

C3

Publicar: GitHub Pages e GitHub Actions

O GitHub Pages publica páginas estáticas: HTML, CSS e JavaScript do navegador. Servidor Node.js não roda lá.

Com o GitHub Actions, cada push publica a versão nova sozinho. Uma alternativa no Azure é o Azure Static Web Apps, que também publica direto do GitHub.

CU1 · caso de uso

Abrir o projeto pelo link

Ator: Visitante (colega, professora, recrutador)

Objetivo: Usar o projeto do grupo sem instalar nada.

Fluxo principal

  1. O visitante recebe o link do GitHub Pages.
  2. Abre no celular ou no computador.
  3. Usa a funcionalidade principal.
  4. Volta outro dia e encontra a mesma versão no ar.

E se...

  • O projeto precisa de um servidor Node.js: o GitHub Pages não roda servidor. O que o grupo faz?

Para pensar

  1. Qual é a funcionalidade principal do projeto de vocês? Ela funciona só no navegador?
  2. O que precisa estar no README para o visitante entender o projeto?
