Antes da atividade

C1

Função anônima e arrow function

Uma função pode ser guardada numa variável. Sem nome próprio, ela é anônima.

A arrow function é o jeito curto de escrever: (parâmetros) => resultado. Com uma linha só, o return fica implícito.

1// função tradicional2function dobro(n) {3  return n * 2;4}56// anônima, guardada numa variável7const triplo = function (n) {8  return n * 3;9};1011// arrow function: o return está implícito12const quadrado = (n) => n * n;1314console.log(quadrado(4));   // 16
C2

Escopo: onde a variável existe

Global: declarada fora de tudo, vale no arquivo inteiro. De função: só dentro da função. De bloco: só dentro das chaves { } onde nasceu.

let e const respeitam o bloco. O var não, e é por isso que ele causa tanta confusão.

1const turma = "ADS";           // global23function mostrar() {4  const sala = "Lab 3";        // de função5  if (true) {6    let hora = "19h";          // de bloco7    console.log(turma, sala, hora);8  }9  // console.log(hora);  // erro: hora não existe aqui10}11mostrar();
CU1 · caso de uso

Aplicar desconto na mensalidade

Ator: Secretaria financeira

Objetivo: Calcular a mensalidade com o desconto certo para cada aluno.

Fluxo principal

  1. A secretaria escolhe o aluno.
  2. O sistema identifica o tipo de desconto (pontualidade, irmãos ou bolsa).
  3. Calcula a mensalidade final.
  4. Mostra o valor.

E se...

  • O aluno não tem desconto: a mensalidade fica cheia.

Para pensar

  1. Cada desconto pode ser uma arrow function curta. Como ficariam?
  2. Onde a variável do valor final deve existir: dentro ou fora da função? (escopo)
