Como um sistema toma decisões?

P1 · o problema

Quem é aprovado?

A regra da faculdade: para ser aprovado, é preciso ter pelo menos 75% de frequência e média 6,0. Em grupo, desenhem no Whiteboard o fluxograma dessa decisão antes de escrever qualquer linha de código.

C1–C3 · conceitos

Decidindo no código

C1

if, else e else if

O if executa um bloco só se a condição for verdadeira. O else é o caminho contrário. O else if testa outra condição no meio do caminho.

Condições compostas usam os operadores lógicos da aula passada.

1const media = 5.5;2const frequencia = 80;34if (frequencia < 75) {5  console.log("Reprovado por falta");6} else if (media >= 6) {7  console.log("Aprovado");8} else {9  console.log("Recuperação final");10}
C2

Ternário: decisão de uma linha

Para escolher entre dois valores, o ternário economiza linhas: condição ? seVerdadeiro : seFalso.

Use só em decisões simples. Se precisar de mais de um ?, volte para o if.

1const media = 7.5;2const situacao = media >= 6 ? "Aprovado" : "Em recuperação";3console.log(situacao);   // Aprovado
C3

switch: o menu de opções

Quando uma variável pode assumir vários valores fixos, o switch fica mais legível que uma fila de else if.

O break encerra cada caso. O default pega o que não se encaixou em nenhum.

Cuidado: esqueceu o break? O código continua executando os casos de baixo.

1const opcao = prompt("1 média, 2 situação, 3 frequência");23switch (opcao) {4  case "1":5    console.log("Consultando a média...");6    break;7  case "2":8    console.log("Consultando a situação...");9    break;10  case "3":11    console.log("Consultando a frequência...");12    break;13  default:14    console.log("Opção inválida");15}
