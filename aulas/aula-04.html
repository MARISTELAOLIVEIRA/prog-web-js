C1–C3 · conceitos

Os operadores da calculadora

C1

Aritméticos e atribuição

As contas de sempre: +, -, *, /. E mais dois: % (resto da divisão) e ** (potência).

A precedência é a da matemática: parênteses primeiro. Para atualizar uma variável, use os atalhos +=, -=, ++ e --.

1const preco = 200;2const desconto = preco * 0.1;     // 203const total = preco - desconto;   // 18045console.log(10 % 3);    // 1  (resto)6console.log(2 ** 3);    // 8  (potência)7console.log(2 + 3 * 4);   // 148console.log((2 + 3) * 4); // 20910let itens = 1;11itens++;          // 212itens += 3;       // 5
C2

Relacionais: comparando

Comparações respondem true ou false: >, <, >=, <=, === e !==.

Cuidado: == compara só o valor e converte o tipo sozinho. === compara valor e tipo. Use sempre ===.

1console.log(180 > 150);    // true2console.log(5 == "5");     // true   (converteu o tipo!)3console.log(5 === "5");    // false  (tipos diferentes)4console.log(5 !== "5");    // true
C3

Lógicos: juntando condições

&& (E) exige as duas condições. || (OU) se contenta com uma. ! (NÃO) inverte.

É assim que nascem as regras de negócio.

1const total = 180;2const aVista = true;34const freteGratis = total >= 150;            // true5const ganhaDesconto = aVista && total > 100; // true6const temBrinde = total > 500 || aVista;     // true7console.log(!freteGratis);                   // false
